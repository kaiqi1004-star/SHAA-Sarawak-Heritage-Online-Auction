SHAA Simple Website Setup
=========================

1. Open XAMPP and start Apache + MySQL.
2. Go to http://localhost/phpmyadmin
3. Create database named: shaa_db
4. Import your shaa_db.sql file.
5. Copy the shaa_website folder into: C:\xampp\htdocs\
6. Open browser: http://localhost/shaa_website/index.php

Main pages:
- index.php: Dashboard
- users.php: Add, update, delete users
- items.php: Add, update, delete auction items
- bids.php: Add and delete bids
- orders.php: View orders
- payments.php: View payments
- reports.php: Shows the 5 required project reports

If your MySQL password is not empty, edit config.php.
